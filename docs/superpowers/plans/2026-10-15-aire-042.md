# Aire 0.4.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Repair newly reproduced correctness gaps and systemize future audits in 0.4.2.

**Architecture:** Preserve existing runtime boundaries. Add installed-user smoke diagnostics to doctor and a separate repository audit runner with source-bound JSON evidence; CI consumes the same runner.

**Tech Stack:** Python, pytest, Typer, uv, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-15-audit-loop-design.md`

## Global Constraints

- Keep Python >=3.11, the four existing runtime dependencies and all public extras.
- No new runtime dependency.
- Retain lazy imports, release integrity gates and digital attestations.
- QA optional CPU backends with bounded threads.

## Review Focus

- Secret values in nested/custom config fields must not appear in diagnostics.
- Invalid explicit paths must never fall back to a different project configuration.
- Mutating records inside a failed transform must not change the source dataset.
- Overlapping tasks sharing one context must restore their own ambient context.
- Interrupted audits and changed source trees must never produce a healthy report.
